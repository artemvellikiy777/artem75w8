## 📖 Описание

Random Password Generator — это графическое приложение на Python с использованием библиотеки Tkinter для генерации случайных паролей с настраиваемыми параметрами. Программа позволяет выбирать длину пароля, типы используемых символов, сохраняет историю сгенерированных паролей в JSON-файл и поддерживает копирование в буфер обмена.

## 🚀 Функциональность

- ✅ Генерация случайных паролей  
- ✅ Настройка длины пароля (от 4 до 50 символов)  
- ✅ Выбор типов символов:
  - Цифры (0-9)
  - Буквы (A-Z, a-z)
  - Специальные символы (!@#$%^&*()_+-=[]{}|;:,.<>?)
- ✅ Копирование пароля в буфер обмена  
- ✅ Сохранение истории паролей в JSON  
- ✅ Просмотр последних 10 паролей в таблице  
- ✅ Очистка истории
